## 📖 关于本项目

本项目是针对**吉林大学白求恩第一临床医学院五年制《预防医学》课程**中“医学统计学”板块定制的复习资料。它略去了晦涩的数学推导，专注于帮你理清“怎么选公式”和“怎么算结果”。

我们深知，统计学只是预防医学拼图中的一块。在备考的最后阶段，希望这份资料能化作一盏微光，陪你度过期末复习的长夜。

## 🎯 核心内容

本项目包含以下核心模块，旨在助你期末“速通”：

- **📚 考点拆解**：基于 2022 版教学大纲与 2023 级授课 PPT，提炼核心考点。
- **🗺️ 判别图谱**：从“设计类型”到“统计方法”的决策树，一眼看穿题目套路。
- **🧮 公式速查**：汇总 t 检验、卡方检验、秩和检验的核心公式，考前背诵专用。
- **📝 编者心语**：收录复习时的易错点辨析与逻辑思考（虽然有点啰嗦，但很实用）。

> **⚠️ 适用范围提示**：
> 本资料专为**五年制临床医学**课程深度定制。
> 对于 **5+3 一体化**或更长学制的同学，由于《医学统计学》为独立课程，内容更深、考察更难，本资料可能覆盖不足，仅建议作为辅助参考。

## 🛠️ 如何使用

### 1. 直接获取 PDF
请前往本仓库的 [Releases 页面](https://github.com/Mading706/Medical-Statistics/releases) 下载最新编译好的 PDF 文件（`Medical_Statistics_Review.pdf`）。

### 2. 本地编译 (For Developers)
如果你想自己修改内容或排版，可以克隆本项目进行编译：

1.  Clone 仓库：
    ```bash
    git clone [https://github.com/Mading706/Medical-Statistics.git](https://github.com/Mading706/Medical-Statistics.git)
    ```
2.  确保本地安装了 TeX Live 或 MiKTeX 环境。
3.  使用 **XeLaTeX** 编译器编译 `main.tex` 文件。
4.  本项目基于 [ElegantBook](https://github.com/ElegantLaTeX/ElegantBook) 模板构建。
